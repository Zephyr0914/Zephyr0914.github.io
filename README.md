## 🚀 How to View Locally or Deploy

### Option 1: Open Directly in Browser
Double-click `index.html` or open it in any modern browser:
```bash
start index.html
```

### Option 2: Deploy to GitHub Pages (Recommended)
1. Initialize a git repo in this folder:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   ```
2. Create a repository on GitHub (e.g. `Zephyr0914.github.io` or `portfolio`) and push:
   ```bash
   git branch -M main
   git remote add origin https://github.com/Zephyr0914/portfolio.git
   git push -u origin main
   ```
3. Enable GitHub Pages in repository settings.
